# Convenções permanentes

Os indicadores deste projeto devem ser atualizados exclusivamente a partir de `Base de Dados/dados 2025.xlsx` e `Base de Dados/dados 2026.xlsx`.

Não ler nem executar o arquivo de contatos do Power BI. Ele será usado futuramente pelo usuário para abastecer as planilhas.

Preservar as planilhas e os PDFs originais. Distinguir dados recalculados, divergências históricas e pareceres herdados. Não substituir valores ausentes com números dos PDFs. Não excluir registros residuais sem regra expressa. Usar as definições documentadas em LEIA-ME.md.

Manter o gerador reproduzível, a identidade AlfaMen e os arquivos auxiliares locais. Alterar o template, regenerar e validar, em vez de corrigir manualmente apenas o HTML final.
